# int_to_roman

Write a function `int_to_roman(n: int) -> str` that converts an integer with `1 <= n <= 3999`
to its standard Roman numeral in uppercase. Use the symbols I=1, V=5, X=10, L=50, C=100, D=500,
M=1000 and the standard subtractive forms IV, IX, XL, XC, CD and CM; never repeat a symbol more
than three times in a row.

Example: `int_to_roman(1994)` returns `"MCMXCIV"`.
