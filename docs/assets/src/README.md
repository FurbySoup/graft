# docs/assets/src

Sources for the README's visual assets. Every committed SVG in `docs/assets/` is generated by a zero-dependency Node ESM script here, with byte-identical output on every run, so edit the script, never the SVG. The two Mermaid files (`evidence-chain.mmd`, `dev-loop.mmd`) mirror the diagrams inlined in the top-level README. GitHub renders those itself, so they have no build step. Keep them in sync by hand.

Regenerate from the repo root (Node 22):

```sh
node docs/assets/src/wordmark.mjs     # graft-wordmark-{light,dark}.svg
node docs/assets/src/merge-gate.mjs   # merge-gate-{light,dark}.svg
```

SVG rules (GitHub serves images through its camo proxy inside `<img>`):

- No `<script>`, no `foreignObject`, and no external `href`s, fonts or images. Animation is CSS `@keyframes` only, and it must respect `prefers-reduced-motion`.
- Font stack: `system-ui,-apple-system,"Segoe UI",Helvetica,Arial,sans-serif`.
- Backgrounds are transparent. The light/dark pair is swapped with `<picture>`.
- Every SVG has a `<title>` and a `<desc>`. Check that it parses with `python3 -c "import xml.etree.ElementTree as E,sys;[E.parse(f) for f in sys.argv[1:]]" docs/assets/*.svg`.
